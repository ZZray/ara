# 一次性 SSH 远程支持

作者：Ray Zhang。范围：`tools/ssh-tunnel`，2026-11-02。

该工具独立于 ARA Agent Core 和 LabSlot 业务。云端只中转 SSH 字节，使用内存保存本次配对；主控可管理多个被控，被控启动一次只接受一个主控。现场账号密码留在现场 PowerShell 进程内，安装包没有共享私钥。

## 必须保留的边界

- 一次性配对码在云端原子领取，并绑定已经证明持有私钥的主控身份。知道设备 ID 不提供连接或关闭权限。
- 连接断开、主控退出或云端重启后，本次授权失效。恢复连接要重新启动和配对，不重放 SSH 命令。
- 目标主机公钥来自现场有效 SSH 配置和文件，主控按该公钥核验。外层服务器公钥通过经过证书验证的同源 HTTPS 获取。
- 隧道断开不等于现场授权文件已清理。正常退出撤销本次新增的公钥和规则；强杀、断电或未知安装状态可能需要人工根据回执清理，不能报告全部撤销。
- 远程安装依赖既有管理员共享和 WMI/DCOM。只有用户名和密码，无法在这些通道不可达时安装 SSH；离线入口也不能证明远程管理或入站访问已经可用。
- 安装或授权已提交但结果未知时，禁止与原操作并行清理或重放。重新操作前核对回执和进程状态。

## 已遇到的兼容问题

PowerShell 5.1 默认读取无 BOM 文本时可能按系统代码页解释，中文账号和路径会损坏。回执统一写 UTF-8，所有读取端明确指定 UTF-8。

OpenSSH 的 `UserKnownHostsFile` 同时解析空格和百分号。仅把它作为单个进程参数传递仍不够；路径需按 SSH 配置语法引用并转义 `%`。真实 `ssh.exe` 夹具覆盖这两个字符及错误主机密钥拒绝。

Nginx reload 后旧 worker 可能短暂处理旧路由。部署验收检查健康响应正文，不能把重定向到业务登录页当成中转上线。

## 安装交互

统一 EXE 使用标准 Windows 安装页面，只增加主控、被控两个单选项。选择决定桌面默认入口，开始菜单保留两者。没有自定义动效；安装完成与连接成功分开显示。静默参数 `/S /ROLE=controller|controlled` 只安装文件，不启动设备连接或修改 SSH 服务。
