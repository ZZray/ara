## Surface behavior notes

- **REPO-PKG-META**: Publishing metadata and release notes; CHANGELOG entries are read as behavior hints only.
- **AGT-LOOP**: agentLoop/agentLoopContinue event sequence, tool call validation and execution, steering/follow-up queues, abort and synthetic tool results, provider message normalization.
- **AGT-AGENT**: Agent state, busy errors, prompt/continue/abort, event subscription, steering and follow-up message modes, pause gate.
- **AGT-APPEND-CTX**: Prefix-stable append-only context for provider cache reuse.
- **AGT-COMPACTION**: Token-threshold compaction, summaries with file operations, remote/OpenAI compaction, pruning and tool-output protection, handoff documents.
- **AGT-PROXY**: Proxy-backed stream with partial JSON tool-call reassembly and disconnect handling.
- **AGT-TELEMETRY**: OpenTelemetry spans/metrics and run summary collection.
- **AGT-TOKENIZER**: Token counting/estimation used for context budgets.
- **AI-STREAM-CORE**: User/assistant/toolResult messages, content blocks, usage and stop reasons, AssistantMessageEvent stream protocol.
- **AI-OPENAI-CHAT**: Chat Completions request shaping, SSE parsing, tool-call deltas, reasoning fields, usage, finish reasons, compat flags.
- **AI-OPENAI-RESPONSES**: Responses API items, reasoning items, encrypted content replay, Codex transport and usage.
- **AI-ANTHROPIC**: Messages API SSE, thinking signatures, cache control, tool schema, retries.
- **AI-GOOGLE**: Gemini generateContent streaming, function calls, thought signatures.
- **AI-BEDROCK**: Converse stream, event-stream framing, SigV4, credentials.
- **AI-CURSOR**: Cursor agent transport, exec handlers, tool bridges.
- **AI-DEVIN**: Devin transport, framing and history.
- **AI-GITLAB**: GitLab Duo chat/workflow transport.
- **AI-COPILOT**: Copilot headers, base URL, reasoning routing.
- **AI-OLLAMA**: Ollama chat transport and thinking control.
- **AI-KIMI**: Kimi transport and multi-account usage.
- **AI-PROVIDERS-MISC**: Synthetic, cowork, pi-native, grammar-constrained and header helpers.
- **AI-MOCK**: Deterministic scripted provider for tests.
- **AI-TRANSFORM**: Replay of foreign-provider history, orphaned tool calls, images for non-vision models.
- **AI-REGISTRY**: Registration and dispatch of wire APIs to providers.
- **AI-SERVERS**: Local OpenAI/Anthropic/pi-native compatible servers fronting providers.
- **AI-AUTH**: Credential stores, OAuth flows and refresh, broker, provider auth hooks. Hosts own identity and grants.
- **AI-DIALECT**: Text-encoded tool calls and thinking fences for models without native tools.
- **AI-ERROR**: Retryable/auth/rate-limit/overflow classification, abort errors, formatting.
- **AI-RETRY**: Retry-After parsing, one-shot retries, idle stream timeouts, abort source tracking.
- **AI-STREAM-GUARDS**: Leaked thinking/harmony markup repair, repeated tool-call and thinking loop detection.
- **AI-TOOLSCHEMA**: JSON Schema normalization per provider, argument validation and coercion, tool choice mapping.
- **AI-USAGE**: Account usage/quota queries per provider.
- **AI-HTTP-DEBUG**: Request/response capture for diagnostics (credential redaction required).
- **AI-TEST-TRIAGE**: Fallback for packages/ai tests/scripts not owned by a feature surface (currently only debug scripts); new unowned files land here and must be reassigned.
- **CA-SESSION-JOURNAL**: Append-only session tree with ids/parents, header, message/model/compaction entries, atomic persistence, resume, listing.
- **CA-SESSION-BACKENDS**: SQLite/Redis/indexed storage and prompt history; hosts choose storage location.
- **CA-SESSION-FOREIGN**: Import of other agents' session logs.
- **CA-AGENT-SESSION**: Binding Agent events to session persistence, model/tool selection, retries, compaction triggers, branching, steering, disposal.

- **CA-QUEUE**: Message queueing semantics during a running turn.
