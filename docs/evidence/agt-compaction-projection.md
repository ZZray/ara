# AGT-COMPACTIONe: typed Session compaction projection (WIP)

Fixed OMP source: `596f2da7101178214aa27a753529d15e6b7ad91d`, `packages/coding-agent/src/session/session-context.ts:238-305,424-492` and `packages/agent/src/compaction/messages.ts:49-68,232-251`. OMP selects the last compaction on the active branch and presents its summary before the kept messages and later messages. Its Agent message type keeps a compaction summary distinct before converting it into an attributed model input.

ARA adds `SessionJournal::compacted_context_projection()` as a strict, read-only step toward that behavior. It returns a typed summary item and source-tagged messages; it does not convert the summary to an ordinary user message. It preserves the raw journal and the existing tolerant `build_context()` contract. It shares the strict rooted-branch validation with `compaction_source_snapshot()`, rejects unsupported context entries and undecodable messages, validates each soft compaction record, and exposes only the latest summary. The replaced prefix must end at a completed assistant turn, retain paired tool receipts, contain no unknown tool effect, image, or developer message, and the first kept message must be a user message. A `sourceEntryIds` list, when present, must exactly match raw message IDs before `firstKeptEntryId` on the current branch. Imported legacy entries without that field are projected with `source_entry_ids: None` and have no verified provenance. Remote, handoff, snapcompact, provider replay payloads, and extension preserve data require separate semantics and are rejected.

This projection is not connected to the Agent/CLI model request. It does not select a cut, invoke a model, write a compaction entry, serialize concurrent Session writers, recheck the durable leaf, or prove a context-budget fit. In particular, a lock used only by a future compaction writer would not protect against ordinary `append_raw`/`rewrite`, which currently do not use that lock. Any durable writer requires a separately reviewed change to the stable Session write path.
