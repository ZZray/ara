## Durable representation and lifetime limits

Typed AgentTool returns owned serde values; the facade has no original Native reference identity. Typed keys therefore compare owned ordered values and retain Weak tool identity only where Derived callbacks require it. Typed results promise exposed values, while same-schema identity memoization is exercised on the actual Graph path. Typed/Graph prefix domains remain isolated; neither domain fabricates the other's identity.

The current ValueHeap is an arena without per-node GC. Identity tables use Weak<ValueHeap> plus checked DeferredValue tokens and hold no strong heap/runtime lease. Dead heap tables are pruned on a later operation. This avoids an Arc cycle under the current arena lifetime; it does not claim general WeakMap/ephemeron collection semantics. Future per-node collection must account for weak keys and cached-value edges.

PropertyNames reuse keeps the validator's returned boolean as `success`, matching exact upstream `validateSchemaValueInRoot`; it is not redefined as issues.is_empty(). Existing strict exporter, checked JSON bridge, unknown effect/approval handling and original unrelated WIP are preserved.
