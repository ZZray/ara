Fixed OMP source: `596f2da7101178214aa27a753529d15e6b7ad91d`, `packages/agent/src/compaction/compaction.ts:873-954` (`summarizeConversationWindow`). OMP sends the summary system template and one user prompt to `instrumentedCompleteSimple`, then joins visible text blocks with newlines. ARA's `ara-agent::compaction::summarize_sources` uses the existing `ModelProvider` port with the [source-tagged prompt](agt-compaction-input.md), a caller-selected output-token limit, deadline and cancellation token. The request advertises no tools. This layer makes one logical provider call and does not retry it; the underlying OpenAI-compatible provider may retry its HTTP POST before streaming according to its configured policy. There is no journal write, Session replay change or Agent loop tool execution.

ARA intentionally accepts only a terminal `Done` whose event and message both say `Stop`, with no error fields or tool-call event/block and nonempty visible text. Thinking and signatures are omitted. Images and output beyond 1 MiB fail. OMP's current summary helper only explicitly rejects an `error` stop and may return empty/partial text; the stricter ARA rule prevents an incomplete derived context from becoming eligible for persistence. Success returns only visible text, this window's source entry IDs, host-selected model ID, response ID, usage and timings. A prior summary's source IDs are **not** included in `window_source_entry_ids`; the Session owner must link prior provenance separately. A failure retains terminal usage when available, plus bounded provider status/diagnostic; missing usage stays unknown. Provider diagnostics may echo request data and must be redacted before logging or display.
