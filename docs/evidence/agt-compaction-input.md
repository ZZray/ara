# AGT-COMPACTIONa: source-tagged summary input (WIP)

Fixed OMP source: `596f2da7101178214aa27a753529d15e6b7ad91d`, `packages/agent/src/compaction/utils.ts:205-328` and `compaction.ts:928-1015`. The three templates in `crates/ara-agent/prompts/` byte-match that commit's `packages/agent/src/compaction/prompts/`; their MIT source is recorded in `THIRD_PARTY_NOTICES.md`.

`ara-agent::compaction` prepares a one-shot summary prompt from caller-supplied journal entry IDs and messages. It carries source IDs into JSONL records, retains visible role, tool calls, stop reason and tool receipts, flags the native recovery receipt for an interrupted tool with unknown effects, and excludes private thinking, redacted payloads and signatures. Images fail explicitly. Untrusted `<conversation>` and `<previous-summary>` tags are escaped, and the serializer is bounded to 256 source messages and 1 MiB. The raw transcript remains untouched.

Intentional differences from fixed OMP: JSONL fields prevent message content from impersonating an entry ID or role; private reasoning is always excluded; tool-result truncation uses Unicode scalar values rather than JavaScript UTF-16 units so it cannot split a Rust UTF-8 string. ARA rejects oversized input rather than claiming it fits a model window. Source-tag syntax is checked, but this pure Agent function cannot prove that the ID identifies that message in the active Session branch. The future Session caller must validate that relationship and record the exact IDs.

The function does **not** select a safe cut point, validate complete turns or tool-call/result pairs, call a model, check its context window, write a compaction entry, change replay context, or resume a Run. These are required before AGT-COMPACTION or A3 acceptance. A successful serialization is not evidence that a turn is safe to compact. The manual host path also needs a concurrent-writer decision before touching Session writes; no Session, CLI or live installation code changed in this slice.

Windows verification on this snapshot: `cargo test -p ara-agent` passed 21 loop, 9 compaction and 4 tokenizer tests plus doc tests; `cargo clippy -p ara-agent --all-targets --all-features -- -D warnings` passed; scoped formatting and `git diff --check` passed. `cargo deny check` and `python scripts/omp_inventory.py check` passed (deny retains existing duplicate-version warnings). Tests cover boundary-tag escaping, long malformed brackets, forged role labels, private data exclusion, image failure, unknown-effect receipt, size/source limits, Unicode truncation and initial/update prompts. Three independent pre-implementation reviews compared scope, journal boundaries and performance. The independent post-implementation review found a quadratic tag scan, plaintext source-label impersonation and omitted unknown-effect status; all three were corrected and the reviewer rechecked the diff with no remaining P0/P1 finding. Full backend verification and a real long-context task have not run on this snapshot. This is a WIP point, not delivery acceptance.
