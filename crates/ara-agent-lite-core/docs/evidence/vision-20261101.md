## 覆盖的失败与历史路径

- 图片工具结果在下一轮真实 loopback HTTP 请求中成为 `image_url`，新 Run 仍保留原图。
- 明确 text、缺失模态、顶层与嵌套声明冲突取 text，均在下一次预算预留/HTTP 前拒图；已产生的工具图片仍留在原 journal。
- 带原图历史改由 text/未知模型继续时，普通请求与压缩路径均零 HTTP 拒绝。
- 图片摘要的请求确实包含图片块，JSON 文本不包含原 base64；标签与原消息位置、MIME、哈希匹配。
- `raw_base=100`、`watermark=101` 时，User、ToolResult、Assistant 三种历史图片的绝对索引与附件顺序正确，输入消息不变。
- 图片附件计入字节上限；超限拒绝，Store 不变；纯文本旧路径保持兼容。
- 摘要 HTTP 400 时只发生原摘要请求，不重试、不继续 Agent、不安装新摘要，原图不变。
- Assistant 图片在主 Agent 请求中明确拒绝，防止固定 Chat provider 静默丢弃。
