公共 Agent 跨语言接入：执行结果与剩余门禁

JSONL、Python/Node 客户端，以及 AI Code Review 和 LabSlot 的限定接入候选。

FIELD NOTES

当前结论

公共 JSONL 子进程和 Python/Node 客户端已实现。它们直接调用公共 Harness，由 Harness 使用 Lite Core；产品注入自己的工具、权限和检查器。两个客户端均实际完成同 Session 的两 Run 文件纠错。

限定进程与受控产品工具验收通过

独立 Codex 接受当前 Windows、未触发压缩的 native 与受控产品工具 profile。16 项当前客户端/原生检查、10 项 Node 合同、5 项额外协议检查及 1 项真实产品 Relay 账本检查通过。这些测试类型分别计数，不代表能力任务数量。

真实模型与整体目标尚未通过

第二次 AI Code Review 真实模型试验未形成补丁，最后一次调用触发 length；原 fence 保留。原七项目标仍为 0/7 整体验收。LabSlot 真实数据库、产品默认迁移和发布门禁均保持 OPEN。

产品怎样使用公共层

共享执行链路

  1. 产品 Host

    创建工作区、工具和模型授权；接收工具请求并保存实际操作收据。

  2. JSONL 与客户端

    转发严格关联的回调、检查原件引用；保留传输状态和原终态。

  3. Harness 与 Lite Core

    执行模型/工具循环，调用 Host 验证器，按有效反馈在原 Session 续作。

Rust 产品可直接依赖 Harness；Python、Node 和其他语言通过子进程协议接入。产品继续管理身份、权限、业务数据、调度与最终 Task 验收。公共层不会接受业务 Task，task_accepted 始终为 false。

接口输入与输出约束
tool_call原参数、原 native call ID 与结果收据完整 RPC/Task/Run/tool/args hash 关联，禁止重放
verify实际 Candidate 与已提交 ReviewReceipt核原任务、Run、criteria/authorization revision，再检查实际产物
prepare原检查反馈与剩余预算；返回新 Run ID 和 objective固定 Session、模型、工具、授权与绝对截止时间
cancel通知原回调并等待同一 RPC 的原结算本地等待结束不能证明外部已 join 或回滚

AI Code Review 历史故障回放

当前产品已有工具、受限代码修复和检查流程。本候选复用其真实 Workspace 与工具 schema，在独立历史源码中修复 Git 非 UTF-8 文本导致的 JSON/HTTP 构造失败。允许修改一个源码文件，固定七项测试；未改产品源码、旧 Core pin、生产队列或发布路径。

试验实际结果结论
历史负基线七测试有一次 failure、一次 error，并复现 UnicodeEncodeError本地请求构造故障成立
controlled-v3两 Run/八调用；首次检查失败，后续七测试通过，测试字节未变受控 provider 验证真实产品工具纠错路径
live-v1无补丁时调用检查，未处理前置拒绝形成 Unknown，原 fence 保留已修工具 preflight 的窄分类；原失败不重试
live-v288.504 秒，一 Run/十调用；六 read、七 search、一次已知未启动 checks，零 replace真实模型未形成补丁；模型能力验收未通过
live-v2 最后调用length，4096 output tokens，最终回答为空；请求约 99 KB，输入分配约 992 KB输出长度耗尽；不能归因输入窗口满

Host 仅在同一锁内确认实际 diff 为空时，记录 known_not_started 和 subprocess_started=false，并返回已结算工具错误。调用后的异常仍按未知处理。候选 verify 收到零补丁时的保守 Unknown 仍是明确边界。

没有增加预算、切换模型或清理 fence 来取得成功。下一点在 Core 研究有界长度恢复，保留原 length 消息、调用计数和截止时间；不执行半截工具，不把截断输出当最终结果。

LabSlot 当前范围

现有 LabSlot 已有业务工具和逐次授权检查。Node 候选绑定要求注入真实工具实例、原 schema 转换、权限闭包、数据库回读及持久操作收据；仅开放 Todo 查询和选定 Todo 的优先级更新。

反馈 Run 保持原用户、会话、真实人类消息序号和确认版本。自动续作不能产生新的人类确认。工具返回中文成功或错误文字不足以证明 SQL 效果，必须使用原业务收据和数据库回读。

真实产品验收仍待执行

普通 Node 测试使用注入替身，未证明 TodoService/PostgreSQL。qspin2 项目要求当轮明确编译授权，已有问题仍待用户答复。本轮未构建 API、连接数据库、启动产品或操作设备。线上制品状态未查询。

下一阶段与未覆盖项

  • Core 输出长度的安全有界恢复；本轮 length 失败原件不自动重放。
  • 实际 summary/agent 共享预算、多次压缩、完整 Goal/Job 和全部回调取消矩阵。
  • LabSlot 真实 TodoService/PostgreSQL；AI Code Review 独立模型复审、产品默认迁移和发布。
  • 更多陌生 C++/逻辑/逆向任务及同模型、同任务、同预算对照；目前不能报告泛化提升比例。
  • 跨平台、C ABI 与供应链发布政策。cargo deny exit14，cached advisories 通过，bans/licenses/sources 失败，未作豁免。

报告使用现有本地手绘模板与 humanizer 编辑。静态文档、链接和原件检查单列；此前本地浏览被策略拒绝，本报告不绕过限制，视觉和真实浏览交互仍未验收。未提交、推送、部署或操作设备。
