# 源码目录

作者：Ray Zhang（Ray）。命名空间：`RY`。

状态：目录骨架，尚无功能源码。

| 目录 | 候选职责 | 当前未决定的内容 |
|---|---|---|
| `service/` | 安装注册、配对、连接中转、任务与收据；需要时接入组织模型服务 | 服务端语言、HandWave 提取范围、存储与传输实现 |
| `node/` | 客户端 Host、系统服务、工具后端、按需桌面会话接入、安装身份和执行记录 | Windows 打包方式、进程边界、具体 Computer Use 后端 |
| `controller/` | 本地 Agent 使用的 MCP 接口与 CLI，共享连接及调用逻辑 | 程序语言、MCP 工具合同、登录与配对命令细节 |
| `admin/` | Agent、连接、配对和运行记录管理页，可由 LabSlot 或其他系统挂载 | 页面挂载及单点登录合同，具体页面结构 |

这些目录描述代码职责，不要求每个目录都成为独立进程或独立发布产品。实际构建入口在技术选型后确定。

## 依赖归属

- ARA Lite Core、Harness 和 MCP 适配器继续由 ARA 项目维护，Reach 使用固定版本或提交依赖。
- 产品业务 API/MCP 继续由相应产品维护，Reach 通过公开接口和能力配置接入。
- 通用 Agent 功能在本仓库实现。LabSlot 侧只承担必要的入口、认证和部署接线。
- 后续确有需要时再增加 `contracts/`、`integrations/`、`packaging/` 和 `tests/`，当前不建立空的框架或包管理清单。
